# Godot project - Tower Defense art prototype

**Open this folder in Godot 4.3 or newer** (needs `TileMapLayer`, added in 4.3). Wait for the first asset import, then press F5.
Renderer: GL Compatibility (works on desktop, mobile, web). Window 1280x768, stretch `canvas_items`, keep aspect.

> **Honest status:** this project was written and statically checked (asset paths, JSON, brackets) but **never run in Godot** (no Godot in the build sandbox). Expect to fix small first-run errors. If something fails, copy the exact error text into the chat and it will be fixed.

## What you get
A playable prototype using the real generated assets: Grassland map built from the 47-tile autotile atlas, separate grid layers, 3 towers (5 levels each, fixed base + rotating head), 5 four-direction monsters, projectiles and impact effects.

Controls: pick a tower button -> hover (green = valid cell, red = invalid, translucent ghost + range ring) -> left click to place. Left click a placed tower (nothing selected) to **upgrade Lv1 -> Lv5**. "Send wave" spawns the 5 monsters. "Toggle grid" shows/hides the grid without touching the ground art. Right click cancels.
Gameplay numbers (damage, hp, speed, range, cooldown) are **placeholders** in `data/*.json`; there is no economy yet.

## Layout
```
05_GODOT_PROJECT/
  project.godot
  scenes/main.tscn            main scene (just attaches main.gd)
  scripts/
    main.gd                   demo controller: UI, placement, waves, targeting
    level.gd                  builds layers from data (see below)
    grid_manager.gd           GRID LOGIC (cells, buildable, occupancy) - no rendering
    grid_renderer.gd          GRID RENDERING layer (toggle grid_visible)
    placement_layer.gd        valid / invalid / occupied overlays, ghost, range ring
    tower.gd                  base + head + shadow, build/idle/attack/upgrade/destroy
    monster.gd                4-direction monster, path following, hit/death
    projectile.gd, vfx_one_shot.gd, sprite_frames_builder.gd, data.gd
  data/                       towers.json, monsters.json, map_*.json, tileset json, map_decor.json
  assets/                     imported PNGs (generated by export_godot_project.py)
```
## Level node layers (bottom to top, z_index)
Ground 0, Water 1, Path 2 (TileMapLayer, nearest filter) | Shadows 3, Decals 3, SmallDecor 4, Objects 5 (y-sort) | **Grid 10** | **Placement 11** | **Actors 20** (towers + monsters, y-sort) | Projectiles 25 | Vfx 30 | UI (CanvasLayer). Grid lines are never baked into tiles; hiding the grid or changing placement state never touches the tile layers.

## Regenerating assets
`04_SOURCE_SCRIPTS/` (Python + Pillow): build_grassland -> build_towers -> build_godot_strips -> build_monsters -> **export_godot_project.py** (re-syncs `assets/` and `data/`) -> `validate_godot_project.py` (static checks). See `00_PROJECT_INSTRUCTIONS/05_GODOT_INTEGRATION.md`.
