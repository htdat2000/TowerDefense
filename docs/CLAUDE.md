# CLAUDE.md - Tower Defense (Godot 4, GDScript)

## Product
A playable, exportable top-down 2D tower defense with a controllable character (chase-and-survive + base building). The Godot project is the repo root.
Python tools in `tools/art/` only generate art into `assets/`; they are not part of the game.

## Gameplay rules (implemented, written 2026-11-25, not yet run)
1. A controllable character (WASD / arrows) is on the map. Monsters chase it and attack it. Character death = defeat. Only the character and monsters have HP.
2. Prepare phase first (no monsters, build time). Then waves start on a timer, continuously, without waiting for clears, endless until defeat.
3. The player builds towers any time, also during waves, on any buildable cell inside the build radius around the character (not under the character).
4. The player walks through towers. Monsters cannot.
5. Towers have NO HP. A monster that attacks a tower destroys it in one hit (no refund; only selling refunds).
6. If towers leave no route to the character, monsters path THROUGH towers at a very high cost: they walk to the tower on their cheapest route, attack it, and the route is recomputed.
7. Pathing = 4-direction flow field on the 64 px grid centred on the character cell (`flow_field.gd`). Solid for monsters: water, blocked, towers. Solid for the player: water, blocked.

## Modes (the user states one per chat)
- **GAME**: edit `scripts/`, `scenes/`, `data/`, `project.godot`. Never edit PNGs in `assets/`.
- **ART**: edit `tools/art/` and regenerate `assets/`. Only when `docs/ROADMAP.md` says so.

## Hard rules
- Godot 4.3+ (developed against 4.7.x), GDScript 4, 2D, GL Compatibility, viewport 1280x768, stretch `canvas_items`.
- Top-down. Art tile 32 px, logical grid cell 64 px. Tower footprint 1x1 (2x2 must stay supported).
- Layers stay separate: grid logic (`grid_manager.gd`) / grid render (`grid_renderer.gd`) / placement overlay (`placement_layer.gd`) / tile layers.
- Tower = fixed base + rotating head (art faces EAST, pivot = frame centre). Monster = 4 directions E,S,W,N.
- Gameplay numbers live in `data/*.json`, never in scripts. Current numbers are placeholders.
- `preload` constants, no `class_name` dependencies, typed GDScript, snake_case, 4 spaces, no tabs. Never use `:=` on a value from an untyped variable, annotate the type.
- UI = `Control` nodes + `Theme`, no pixel-positioned UI except prototypes.
- New art needed? Add a line to "Art requests" in `docs/ROADMAP.md` and use a placeholder.
